# Diagnostic key

[Questions](../../assessment/diagnostic.md)

Use 0 = absent/incorrect, 1 = correct claim with incomplete justification, 2 = correct claim with sound justification, for each item. A total out of 10 is only a local descriptive summary, not a validated ability measure. Keep student responses private and share only appropriately aggregated results.

| Item | Form A | Form B |
|---|---|---|
| 1 | Yes: $e_1,e_2,e_1+e_2$ span a plane and are dependent. | Yes: $e_1,e_2,e_3,e_1+e_2$ span $\mathbb R^3$ and are dependent. |
| 2 | Nullity 1; infinitely many vectors, one vector in a basis. | Nullity 1; infinitely many vectors, one vector in a basis. |
| 3 | All $x_0+tv$ solve; subtraction/additivity proves this. | All $z+tw$ solve; subtraction/additivity proves this. |
| 4 | No: $\operatorname{diag}(2,1/2)$ changes the length of $e_1$. | No: $\operatorname{diag}(2,-1/2)$ changes the length of $e_1$. |
| 5 | No: an eigenvector must be nonzero. | No: the equality holds for every matrix and every scalar; a nonzero witness is required. |

For item 3, the displayed family need not be the **entire** solution set unless the kernel is known to be one-dimensional. Award full credit for making this distinction; do not require the student to assert completeness.
