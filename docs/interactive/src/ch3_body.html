3.1

Definition and examples

What makes a set a vector space

A vector space is a set V with an addition and a scalar multiplication that never leave V (closure) and obey eight familiar rules: commutativity and associativity of addition, a zero vector, negatives, and the distributive and associative laws for scalars. Arrows in ℝ2, column vectors in ℝn, m × n matrices, polynomials Pn and continuous functions C[a, b] all qualify.

Once a set is known to be a vector space, every theorem of this chapter applies to it, whatever its elements look like.

3.2

Subspaces

Closed under addition and scalar multiplication; spans and spanning sets

A nonempty subset S of a vector space is a subspace if αx ∈ S whenever x ∈ S, and x + y ∈ S whenever x, y ∈ S. Every subspace contains 0. Two important examples: the null space N(A) = {x : Ax = 0}, and the span of a set of vectors, all their linear combinations.

3.3

Linear independence

Deciding dependence by row reduction

Vectors v1, …, vn are linearly independent if c1v1 + ⋯ + cnvn = 0 forces every ci = 0, and linearly dependent if some nontrivial combination gives 0. Dependent means at least one vector is a combination of the others, so it adds nothing to the span.

How to decide (vectors in ℝm)Put the vectors in the columns of X and solve Xc = 0 by row reduction. Independent ⇔ every column has a pivot. Each free column gives a dependence relation, read off from the reduced row echelon form. Shortcuts: more vectors than entries (n > m) ⇒ dependent; for n vectors in ℝn, independent ⇔ det X ≠ 0 (Theorem 3.3.1).

3.4

Basis and dimension

Minimal spanning sets, maximal independent sets

A basis of V is a linearly independent spanning set. Every vector then has exactly one expression as a combination of the basis vectors (Theorem 3.3.2). All bases of V have the same number of vectors, the dimension of V. In an n-dimensional space, any n independent vectors span, and any n spanning vectors are independent (Theorem 3.4.3).

3.5

Change of basis

Coordinates and transition matrices

If E = [v1, …, vn] is an ordered basis and x = c1v1 + ⋯ + cnvn, then [x]E = (c1, …, cn)T is the coordinate vector of x with respect to E. With U = (u1 … un), standard coordinates are x = U[x]U, so [x]U = U−1x; the transition matrix from basis U to basis V is V−1U.

3.6

Row space and column space

Rank, nullity, and when Ax = b is solvable

The row space of an m × n matrix A is spanned by its rows, the column space by its columns. The rank is the dimension of the row space, which equals the dimension of the column space (Theorem 3.6.6); the nullity is dim N(A).

Theorem 3.6.5 · rank–nullityIf A is m × n, then rank(A) + nullity(A) = n. Bases come straight from the reduced row echelon form U: the nonzero rows of U (row space), the columns of A in pivot positions (column space), one special solution per free variable (null space).
