4.1

Definition and examples

Linear maps, kernel and range

A mapping L from a vector space V into a vector space W is a linear transformation if L(αv1 + βv2) = αL(v1) + βL(v2) for all vectors and scalars. Equivalently, L respects sums and scalar multiples separately. Every matrix gives one, LA(x) = Ax; so do differentiation and integration of functions.

Two quick tests for “not linear”: L(0) ≠ 0 (a translation), or a single pair where scaling or adding fails (a norm, a product of coordinates).

4.2

Matrix representations

Columns are images of basis vectors

Every linear L : ℝn → ℝm is multiplication by the m × n matrix whose jth column is L(ej) (Theorem 4.2.1). With other ordered bases E and F, the representing matrix has columns [L(vj)]F, and then [L(v)]F = A[v]E (Theorem 4.2.2).

Doing L1 first and L2 second is represented by A2A1: the matrix of the first step stands on the right.

    4.3

    Similarity

    One operator, many matrices

    If A represents a linear operator in one basis and B represents it in another, with S the transition matrix from the second basis to the first, then B = S−1AS (Theorem 4.3.1). Matrices related this way are similar. Similar matrices have the same determinant, trace and rank, because they describe the same map.

    Choosing the basis well can make B diagonal (Example 4.3.2). That is the subject of Chapter 6.
