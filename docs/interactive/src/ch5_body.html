5.1

The scalar product in ℝn

Length, angle, projection

The scalar product of x, y ∈ ℝn is xTy = x1y1 + ⋯ + xnyn. It gives length ‖x‖ = (xTx)1/2, distance ‖x − y‖, and angle: xTy = ‖x‖ ‖y‖ cos θ. Vectors are orthogonal when xTy = 0.

The vector projection of x onto y is p = (xTy / yTy) y. What is left over, x − p, is orthogonal to y. Everything in this chapter grows from that picture.

5.2

Orthogonal subspaces

The four fundamental subspaces

The orthogonal complement of a subspace Y of ℝn is Y⊥ = {x : xTy = 0 for every y ∈ Y}. For an m × n matrix A, the equation Ax = 0 says exactly that x is orthogonal to every row, so N(A) = R(AT)⊥; applied to AT, N(AT) = R(A)⊥ (Theorem 5.2.1).

Dimensions add up: dim S + dim S⊥ = n, and every vector splits uniquely as ℝn = S ⊕ S⊥ (Theorems 5.2.2, 5.2.3).

5.3

Least squares problems

The best approximate solution of an inconsistent system

When Ax = b has no solution, choose x̂ to make the residual r = b − Ax as short as possible. Then Ax̂ is the projection p of b onto the column space, and r is orthogonal to every column: ATr = 0. That is the system of normal equations ATAx̂ = ATb, which has a unique solution when A has rank n (Theorem 5.3.2).

Fitting a polynomial of degree k to data points is the special case where column j of A holds the powers xij.

5.4

Inner product spaces

Inner products, norms, distance

An inner product ⟨x, y⟩ is any rule that is positive (⟨x, x⟩ > 0 for x ≠ 0), symmetric, and linear in each argument. Examples: weighted sums Σwixiyi, ⟨A, B⟩ = Σaijbij for matrices, ∫f g for functions. Every inner product gives a norm, angles, projections, the Pythagorean law and the Cauchy–Schwarz inequality |⟨x, y⟩| ≤ ‖x‖ ‖y‖.

A norm need not come from an inner product. The 1-norm and the ∞-norm are norms whose unit circles have corners.

5.5

Orthonormal sets

Coordinates without solving, orthogonal matrices, projections

An orthonormal set consists of mutually orthogonal unit vectors. In an orthonormal basis u1, …, un, the coordinates of x are simply ci = ⟨x, ui⟩, and ‖x‖2 = Σci2 (Parseval). A square matrix Q with orthonormal columns is an orthogonal matrix: QTQ = I, so Q−1 = QT, and Q preserves lengths and angles.

The projection of x onto a subspace with orthonormal basis u1, …, uk is p = Σ⟨x, ui⟩ui = UUTx, the closest point of the subspace (Theorems 5.5.7, 5.5.8).

5.6

The Gram–Schmidt process

Orthonormalize a basis; QR factorization

Given independent a1, …, an, set q1 = a1/‖a1‖ and, for each next vector, subtract its projections onto the q's already built and normalize what is left: rik = qiTak, rkk = ‖ak − Σrikqi‖. The numbers rik fill an upper triangular R with A = QR (Theorem 5.6.2). Then least squares is easy: Rx̂ = QTb (Theorem 5.6.3).

5.7

Orthogonal polynomials

Legendre and Chebyshev

A sequence p0, p1, … with deg pi = i and ⟨pi, pj⟩ = 0 for i ≠ j is a sequence of orthogonal polynomials. They always satisfy a three-term recursion (Theorem 5.7.2). Legendre polynomials use ⟨p, q⟩ = ∫−11 p q dx; Chebyshev polynomials Tn(cos θ) = cos nθ use the weight (1 − x2)−1/2.
