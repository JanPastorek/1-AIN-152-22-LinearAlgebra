2.1

The determinant of a matrix

Minors, cofactors, and expansion along any row or column

For a 2 × 2 matrix, det(A) = a11a22 − a12a21, and A is nonsingular exactly when this number is not 0. Larger determinants are defined inductively: delete a row and a column to get a smaller matrix (a minor), attach a sign, and add up.

Geometrically, |det A| is the area (in 3D, the volume) of the parallelogram spanned by the columns, and the sign records whether the columns keep or reverse the orientation of the plane.

2.2

Properties of determinants

Row operations, singularity, and det(AB) = det(A) det(B)

Each elementary row operation changes the determinant in a predictable way: I. interchanging two rows changes its sign, II. multiplying a row by α multiplies it by α, III. adding a multiple of one row to another leaves it unchanged. So the determinant can be computed by reducing to triangular form and multiplying the diagonal entries, at a cost of about n3/3 operations instead of n!.

Theorem 2.2.2 · Theorem 2.2.3An n × n matrix A is singular if and only if det(A) = 0. For n × n matrices A and B, det(AB) = det(A) det(B).

    Additional topics and applications

    The adjoint, Cramer's rule, and coded messages

    The adjoint adj A is the transpose of the matrix of cofactors. It satisfies A(adj A) = det(A)I, so when det(A) ≠ 0, A−1 = adj A / det(A). Applied to Ax = b, this gives Cramer's rule.

    Theorem 2.3.1 · Cramer's ruleIf A is a nonsingular n × n matrix and b ∈ ℝn, let Ai be the matrix obtained by replacing the ith column of A by b. Then the unique solution of Ax = b is xi = det(Ai) / det(A).
