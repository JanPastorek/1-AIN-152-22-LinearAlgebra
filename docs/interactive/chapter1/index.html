1.1

Systems of linear equations

Solutions, consistency, and the geometry of a 2 × 2 system

A solution of an m × n system is an ordered n-tuple that satisfies every equation at once. A system with at least one solution is consistent; a system with none is inconsistent.

In a 2 × 2 system, each equation is a line in the plane, and a solution is a point lying on both lines. Two lines can meet in one point, be parallel, or coincide. So the solution set has exactly one point, no points, or infinitely many. The same three outcomes hold for every m × n system.

From equations to matrices, and back

Coefficient & augmented matrices · Exercises 1.1.2, 1.1.4, 1.1.5, 1.3.4

To write a system as a matrix: put all variable terms on the left in the order x1, x2, …; give each equation one row and each variable one column; put the right-hand sides in an extra column after the dashed line. A variable that is missing from an equation gets a 0. A variable written with no number in front has coefficient 1 (or −1).

Watch for
  • Terms written out of order, such as −x3 + 2x1: the column is decided by the variable, not by the position in the equation.
  • Once your matrix is right, the page writes the system as Ax = b and as a combination of columns, which is how §1.3 reads it.
1.2

Elimination and row echelon form

Row operations, pivots, lead and free variables (§1.1 → §1.2)

Two systems are equivalent if they have the same solution set. Three elementary row operations on the augmented matrix never change the solution set:

Elementary row operationsI. Interchange two rows.  II. Multiply a row by a nonzero number.  III. Replace a row by its sum with a multiple of another row.

Gaussian elimination uses them to reach a staircase shape. Section 1.1 stops at strict triangular form and finishes by back substitution. Section 1.2 scales each leading entry to 1 (row echelon form) and then clears the entries above the pivots too (reduced row echelon form, Gauss–Jordan reduction). Variables in pivot columns are lead variables; the rest are free and can take any value.

    Matrix arithmetic

    Ax as a linear combination, and the row-times-column rule

    If A has columns a1, …, an, then Ax = x1a1 + x2a2 + ⋯ + xnan. Solving Ax = b means finding weights that combine the columns into b.

    Theorem 1.3.1 · Consistency theoremA linear system Ax = b is consistent if and only if b can be written as a linear combination of the column vectors of A.

      Elementary matrices

      Row operations as multiplication, and the LU factorization

      An elementary matrix is the identity with one row operation applied to it. Multiplying A on the left by E performs that same operation on A. Every elementary matrix is nonsingular, and its inverse undoes the operation.

      If A reduces to upper triangular U using only operation III, then E3E2E1A = U, and A = LU. L is lower triangular with 1s on the diagonal, and its entries below the diagonal are exactly the multipliers lij used during elimination.

      Partitioned matrices

      Block multiplication and the outer product expansion

      Splitting a matrix into blocks lets you multiply block by block. Partition X into its columns x1, …, xn and Y into columns y1, …, yn. Then the product splits into a sum of outer products:

      Outer product expansionXYT = x1y1T + x2y2T + ⋯ + xnynT

      Each term xiyiT is a multiplication table: a column times a row. Every row of it is a multiple of yiT.

      Strassen's algorithm: seven products instead of eight

      Block multiplication applied recursively

      The ordinary rule needs 8 multiplications for a 2 × 2 product, one for each term aikbkj. Strassen (1969) found 7 products M1, …, M7 that combine into the same C = AB, at the cost of extra additions. The formulas never swap the order of a product, so they still hold when the entries are blocks. Split an n × n matrix into four n/2 × n/2 blocks, apply the formulas, and recurse. The cost drops from n3 to nlog₂7 ≈ n2.807 multiplications.

      Application: a linear neural network

      A layer is a matrix–vector product (§1.3); stacking layers is matrix multiplication (§1.4)

      A layer of a neural network takes a vector x and produces h = Wx + b. Row i of the weight matrix W holds the weights on the arrows into neuron i. So each neuron computes one row of W times the column x, plus its bias bi. The next layer does the same with its own matrix.

      Two linear layers collapse into oneW2(W1x + b1) + b2 = (W2W1)x + (W2b1 + b2), by the distributive and associative laws (Theorem 1.4.1).

      Real networks apply a nonlinear function, such as ReLU(t) = max(0, t), after each layer. These labs leave it out on purpose to show the linear algebra alone. They also show why the nonlinearity matters: without it, a network of any depth is just one matrix and one shift.

      Each layer moves the whole plane

      2 → 2 → 2, a batch of 100 points fed as columns of X

      Feed many inputs at once by putting them in the columns of a matrix X. Then H = W1X computes every hidden vector at once, using the column view of §1.3, and the bias shifts every column. Each layer is a linear map of the plane plus a shift, so straight lines stay straight and parallel lines stay parallel. The points are colored like an XOR pattern. A straight line can't separate blue from pink in the input, so no linear network can separate them in the output either.
