# Slovak–English terminology aid

[Course index](../README.md)

Review terms against the lecturer's preferred usage. This is a terminology aid, not a full translation.

| English | Slovak |
|---|---|
| matrix; row; column | matica; riadok; stĺpec |
| system of linear equations | sústava lineárnych rovníc |
| elementary row operation | elementárna riadková úprava |
| determinant | determinant |
| inverse matrix | inverzná matica |
| group | grupa |
| vector space; subspace | vektorový priestor; podpriestor |
| linear combination | lineárna kombinácia |
| linear span | lineárny obal |
| linearly independent | lineárne nezávislé |
| basis; dimension | báza; dimenzia |
| rank | hodnosť |
| kernel / nullspace | jadro |
| image | obraz |
| linear map | lineárne zobrazenie |
| change of basis | zmena bázy |
| dot product | skalárny súčin |
| cross product | vektorový súčin |
| orthogonal projection | ortogonálna projekcia |
| affine space / map | afinný priestor / afinné zobrazenie |
| eigenvalue; eigenvector | vlastná hodnota; vlastný vektor |
| counterexample | protipríklad |
| necessary / sufficient condition | nutná / postačujúca podmienka |

Use “dimension of the kernel” when introducing nullity, to avoid confusing the number of basis vectors with the number of vectors in the space.
